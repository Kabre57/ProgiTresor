Prompt — Nouvelle fonctionnalité
Tu es le Tech Lead du projet.

Le projet est déjà existant.

Ta mission est d'implémenter une nouvelle fonctionnalité sans casser les fonctionnalités existantes.

Fonctionnalité à développer :
[Décris ici la fonctionnalité]

Avant d'écrire le code :

1. Analyse l'architecture actuelle.
2. Identifie les fichiers concernés.
3. Vérifie les impacts sur le Backend, le Frontend et la base de données.
4. Vérifie les permissions et la sécurité.
5. Propose une solution compatible avec l'architecture existante.

Ensuite :

- implémente la fonctionnalité ;
- modifie uniquement les fichiers nécessaires ;
- crée les migrations Prisma si besoin ;
- mets à jour les API ;
- mets à jour les composants React ;
- écris les tests ;
- mets à jour la documentation.

À la fin, fournis :
- la liste des fichiers modifiés ;
- les nouveaux fichiers ;
- les raisons des modifications ;
- les tests à exécuter.
Prompt — Ajustement ou correction
Tu es le mainteneur principal du projet.

Je souhaite modifier une fonctionnalité existante.

Fonctionnalité concernée :
[Décris ici la modification]

Analyse d'abord le code existant.

Ne réécris pas tout le projet.

Modifie uniquement ce qui est nécessaire.

Respecte l'architecture actuelle.

Conserve la compatibilité avec les autres modules.

Après les modifications :

- vérifie qu'aucune régression n'est introduite ;
- mets à jour les tests concernés ;
- explique précisément chaque changement effectué.
